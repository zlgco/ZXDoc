# ZXDoc
ZXDoc는 차량 연구개발, 시험 및 생산 라인의 요구를 충족하기 위해 개발된 자동차 버스 툴체인 소프트웨어입니다. 이 소프트웨어는 ZLG의 하드웨어 도구를 탑재하고 있으며, CAN, CAN FD, LIN, 차량 내 이더넷 데이터 송수신, 데이터 재생, DBC/LDF 파싱, UDS 진단, ECU 플래싱, SOME/IP, XCP/CCP 보정, 시뮬레이션 등 다양한 응용 계층 기능을 지원합니다.

## 주요 특징
- 데이터 전송 및 수신
- DBC/LDF 전송/파싱
- 곡선 분석
- UDS 진단
- ECU 플래싱
- SOME / IP
- 비디오 동기화 재생
- 파이썬 확장 스크립트
- XCP/CCP 보정
- 시뮬레이션

## 기능 목록
|기능 유형|기능 설명|
|---------|---------|
|버스 프로토콜|CAN, CAN FD, LIN, 차량 내 이더넷
|장비 채널 수|제한 없음
|하드웨어 필터링|상위 컴퓨터는 하드웨어 장치 컨트롤러용 버스 패킷을 필터링하는 ID 범위를 설정합니다|
|소프트웨어 필터링|버스 패킷은 시간, 채널, 메시지 ID, 데이터 및 기타 요소에 따라 필터링할 수 있습니다|
|메시지 데이터 전송|us 수준 사이클에서 원시 메시지 예약 전송, 트리거 송신, DBC/LDF 디스패치를 지원하며, 구성 가능한 신호 생성기를 지원합니다|
|메시지 데이터 모니터링|원본 메시지를 실시간으로 표시합니다; DBC/LDF/ARXML 로드 후 데이터를 파싱할 수 있습니다(DBC 신호를 기반으로 한 ARXML 파일은 파싱 전에 ZXDoc에서 DBC 파일로 변환해야 합니다)|
|메시지 데이터 저장|asc, blf, mat, MF4 등 여러 형식으로 메시지 저장을 지원합니다|
메시지 데이터 재생|온라인 및 오프라인 재생을 모두 지원하며, 시간 범위에 따라 파일 재생 횟수, 재생 속도, 재생 버스 데이터를 설정할 수 있습니다|
|메시지 데이터 통계|버스 통신에서 올바른 프레임과 잘못된 프레임 수를 확인할 수 있도록 지원합니다|
|버스 이용|현재 버스 통신 활용도 및 버스 부하 이해 확인을 지원합니다|
|곡선 분석|DBC/LDF 파일을 로드하면 CAN/CAN FD/LIN 버스 데이터 곡선 시연이 가능하여 버스 데이터 변경 사항을 한눈에 명확하게 알 수 있습니다|
|E2E 보안 알고리즘|E2E 보안 알고리즘 라이브러리 가져오기 지원|
|UDS 진단|ISO-15765 및 ISO-14229 프로토콜을 기반으로 하며, 진단 매개변수 및 서비스 설정, 다중 프레임 전송, UDS 기반 플래시 부트로더 설정, 자동 진단 및 ODX 파일 지원 지원|
|ECU 플래싱|ZXDoc과 결합된 CAN FD 인터페이스 카드는 ECU에 소프트웨어 및 데이터 정보를 전송하여 ECU 관리와 소프트웨어 업데이트를 가능하게 합니다|
|SOME / IP|표준 진단 워크플로우 및 ARXML 파일 가져오기 지원|
|XCP/CCP 보정|A2L 파일 가져오기, 보정 매개변수 관리, 가변 곡선의 그래픽 표시 등 다양한 기능을 지원합니다|
|그래픽 패널|스위치, 녹음기, 표시등, 진행 바, 미터기 등 다양한 COM 컨트롤 목록이 있습니다|
|시뮬레이션|CAN 버스 시뮬레이션/패널 시뮬레이션: 데이터베이스를 로드하고 시뮬레이션할 노드를 직접 선택합니다|
|스크립트 확장|파이썬|
|서드파티 API|C++, 파이썬|
|운영 체제|Windows 7/8/10/11|
