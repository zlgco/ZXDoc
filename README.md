# ZXDoc
ZXDoc은 자동차 연구 개발, 테스트 및 생산 라인의 요구를 충족하기 위해 개발한 자동차 버스 툴체인 소프트웨어입니다. CAN, CAN FD, LIN, 차량 내 이더넷 데이터 전송 및 수신을 지원하며, 데이터 재생, DBC 파싱, UDS 진단, SOME/IP, ECU 플래싱, XCP/CCP 교정, 시뮬레이션 및 기타 애플리케이션 계층 기능을 구현할 수 있습니다. CAN/CAN FD/LIN/차량 이더넷 버스를 테스트, 모니터링, 진단 및 개발하는 데 초점을 맞추고 있습니다.

## 주요 기능
- 데이터 전송 및 수신
- DBC/LDF 전송/파싱
- 곡선 분석
- UDS 진단
- ECU 플래싱
- SOME/IP
- 비디오 동시 재생
- 파이썬 확장 스크립트
- XCP/CCP 교정
- 시뮬레이션

## ZXDoc 기능 목록
|기능 유형|기능 설명|
|---------|---------|
|버스 프로토콜|	CAN, CAN FD, LIN, 자동차 이더넷
|장치 채널 수|	제한 없음
|하드웨어 필터링|	호스트 컴퓨터는 하드웨어 장치 컨트롤러가 버스 메시지를 필터링할 수 있도록 ID 범위를 설정합니다.
|소프트웨어 필터링|	버스 메시지는 시간, 채널, 메시지 ID 및 날짜를 ​​기준으로 필터링할 수 있습니다.
|메시지 데이터 전송|	마이크로초 간격으로 원시 메시지를 시간 순서대로 전송하고, 트리거 전송 및 DBC/LDF 메시지 전송을 지원하며, 신호 발생기를 구성할 수 있습니다.
|메시지 데이터 모니터링|	실시간으로 원시 메시지를 표시하며, DBC/LDF/ARXML 파일을 로드한 후 데이터를 파싱할 수 있습니다(DBC 신호를 기반으로 하는 ARXML 파일은 파싱 전에 ZXDoc에서 DBC 파일로 변환해야 합니다).
|메시지 데이터 저장소|	ASC, BLF, MAT, MF4 등 다양한 형식으로 메시지 저장을 지원합니다.
|메시지 데이터 재생|	온라인 및 오프라인 재생을 지원하며, 파일 재생 시도 횟수, 재생 속도, 시간 범위에 따른 버스 데이터 재생 등을 설정할 수 있습니다.
|메시지 데이터 통계|	버스 통신에서 올바른 메시지 프레임과 잘못된 메시지 프레임의 수를 확인할 수 있도록 지원합니다.
|버스 이용|	현재 버스 통신 활용 현황을 확인하고 버스 부하를 파악하는 데 도움이 됩니다.
|곡선 분석|	DBC/LDF 파일을 로드하면 CAN/CAN FD/LIN 버스 데이터 곡선을 보여줄 수 있어 버스 데이터 변경 사항을 쉽게 확인할 수 있습니다.
|E2E 보안 알고리즘|E2E 보안 알고리즘 라이브러리 가져오기를 지원합니다.|
|UDS 진단|ISO-15765 및 ISO-14229 프로토콜을 기반으로 진단 매개변수 및 서비스 구성, 멀티프레임 전송, UDS 기반 플래시 부트로더 구성, 자동 진단 구현을 지원하며 ODX 파일을 지원합니다.
|ECU 플래싱|	CAN FD 인터페이스 카드는 ZXDoc과 연동하여 소프트웨어 및 데이터 정보를 ECU로 전송함으로써 ECU 관리 및 소프트웨어 업데이트를 가능하게 합니다.
|일부/IP|	표준 진단 절차 및 arxml 파일 가져오기를 지원합니다.
|XCP/CCP 교정|	A2L 파일 가져오기, 교정 매개변수 관리 및 가변 곡선의 그래픽 표시를 지원합니다.
|그래픽 패널|	스위치, 데이터 로거, 표시등, 진행률 표시줄, 계량기 등 다양한 COM 제어 기능을 제공합니다.
|시뮬레이션|	CAN 버스 시뮬레이션/패널 시뮬레이션: 데이터베이스를 불러와 시뮬레이션할 노드를 직접 선택합니다.
|확장 스크립트|	파이썬|
|타사 API|	C++, 파이썬|
|운영 체제|윈도우 7/8/10/11|
