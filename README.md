# ZXDoc
ZXDoc은 친환경차의 연구개발(R&D), 시험·검증, 양산 라인 요구에 맞춰 개발된 차량용 버스 툴체인 소프트웨어입니다. ZLG의 하드웨어 장비와 연동하여 CAN, CAN FD, LIN, 차량용 이더넷 데이터의 송수신 및 재생, DBC/LDF 파싱, UDS 진단, ECU 플래싱, SOME/IP, XCP/CCP 캘리브레이션, 시뮬레이션 기능을 제공합니다.

## 주요 기능
- 데이터 송수신
- DBC/LDF 송수신 및 파싱
- 그래프 분석
- UDS 진단
- ECU 플래싱
- SOME/IP
- 영상 동기화 재생
- 파이썬 확장 스크립트
- XCP/CCP 캘리브레이션
- 시뮬레이션

## 기능 목록
|기능 유형|기능 설명|
|---------|---------|
|버스 프로토콜|CAN, CAN FD, LIN, 차량용 이더넷|
|장비 채널 수|제한 없음|
|하드웨어 필터링|호스트 PC에서 ID 범위를 설정하면 하드웨어 장치 컨트롤러가 해당 범위의 버스 패킷을 필터링합니다.|
|소프트웨어 필터링|시간, 채널, 메시지 ID, 데이터를 기준으로 버스 메시지를 필터링합니다.|
|메시지 데이터 전송|마이크로초(μs) 단위 주기 전송, 원본 메시지 타이밍 전송, 트리거 전송을 지원하며, DBC/LDF 메시지 생성 및 신호 제너레이터 설정이 가능합니다.|
|메시지 데이터 모니터링|원본 메시지를 실시간으로 표시하고, DBC/LDF/ARXML 파일을 불러와 신호 단위로 해석할 수 있습니다. (DBC 신호 기반 ARXML 파일은 ZXDoc에서 DBC 파일로 변환한 후 해석해야 합니다.)|
|메시지 데이터 저장|ASC, BLF, MAT, MF4 등 다양한 형식의 저장을 지원합니다.|
|메시지 데이터 재생|온라인·오프라인 재생을 지원하며, 시간 구간에 따라 재생 횟수, 재생 속도, 재생할 버스 데이터를 설정할 수 있습니다.|
|통계 리포트|버스 통신의 정상 프레임과 오류 프레임 수를 확인할 수 있습니다.|
|버스 사용률|현재 버스 사용률을 확인하여 버스 부하 상태를 파악할 수 있습니다.|
|그래프 분석|DBC/LDF 파일을 불러오면 CAN/CAN FD/LIN 버스 데이터를 그래프로 표시하여 데이터 변화를 한눈에 파악할 수 있습니다.|
|E2E 보안 알고리즘|E2E(End-to-End) 보호 알고리즘 라이브러리 불러오기를 지원합니다.|
|UDS 진단|ISO 15765 및 ISO 14229 프로토콜 기반으로 진단 파라미터·진단 서비스 설정, 멀티프레임 전송, UDS 기반 플래시 부트로더 설정, 자동 진단 실행 등을 지원하며 ODX 파일을 사용할 수 있습니다.|
|ECU 플래싱|ZXDoc과 연동되는 CAN FD 인터페이스 카드를 통해 소프트웨어 및 데이터 정보를 ECU로 전송하여 ECU 관리와 소프트웨어 업데이트를 수행합니다.|
|SOME/IP|표준 진단 절차 및 ARXML 파일 불러오기를 지원합니다.|
|XCP/CCP 캘리브레이션|A2L 파일 불러오기, 캘리브레이션 파라미터 관리, 측정 변수의 그래프 표시를 지원합니다.|
|그래픽 패널|스위치, 레코더, 표시등, 진행률 표시줄, 게이지 등 다양한 COM 컨트롤을 제공합니다.|
|시뮬레이션|CAN 버스 시뮬레이션 및 패널 시뮬레이션을 지원하며, 데이터베이스를 불러온 뒤 시뮬레이션할 노드를 직접 선택할 수 있습니다.|
|확장 스크립트|파이썬|
|서드파티 API(2차 개발용)|C++, 파이썬|
|운영체제|Windows 7/8/10/11|
