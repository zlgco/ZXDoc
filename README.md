# ZXDoc
ZXDoc은 자동차 연구개발, 테스트 및 생산 라인의 요구를 충족하기 위해 개발한 자동차 버스 툴체인 소프트웨어입니다. CAN, CAN FD, LIN, 차량용 이더넷 데이터 송수신을 지원하며, 데이터 재생, DBC 파싱, UDS 진단, SOME/IP, ECU 플래싱, XCP/CCP 교정, 시뮬레이션 등 애플리케이션 계층 기능을 구현할 수 있습니다. CAN/CAN FD/LIN/차량용 이더넷 버스를 테스트, 모니터링, 진단 및 개발하는 데 유용한 도구입니다.

## 주요 기능
- 데이터 송수신
- DBC/LDF 전송/파싱
- 그래프 분석
- UDS 진단
- ECU 플래싱
- SOME/IP
- 동영상 동기화 재생
- 파이썬 확장 스크립트
- XCP/CCP 교정
- 시뮬레이션

## 기능 목록
|기능 유형|기능 설명|
|---------|---------|
|버스 프로토콜|CAN, CAN FD, LIN, 차량용 이더넷|
|장비 채널 수|무제한|
|하드웨어 필터링|PC에서 ID 범위를 설정해 하드웨어 장치 컨트롤러가 버스 메시지를 필터링하도록 합니다|
|소프트웨어 필터링|시간, 채널, 메시지 ID 및 데이터를 기준으로 버스 메시지를 필터링합니다|
|메시지 데이터 전송|us 단위 주기의 원본 메시지 정시 전송, 트리거 전송, DBC/LDF 메시지 생성 및 구성 가능한 신호 생성기를 지원합니다|
|메시지 데이터 모니터링|원본 메시지를 실시간으로 표시하고 DBC/LDF/ARXML을 로드한 후 데이터를 파싱할 수 있습니다(DBC 신호를 기반으로 하는 ARXML 파일은 파싱하기 전에 ZXDoc에서 DBC 파일로 변환해야 함)|
|메시지 데이터 저장|ASC, BLF, MAT, MF4 등 다양한 형식의 메시지 저장을 지원합니다|
|메시지 데이터 재생|온라인 및 오프라인 재생을 지원하며, 시간 범위, 파일 재생 횟수, 재생 속도 및 재생 버스 데이터를 설정할 수 있습니다|
|메시지 데이터 통계|버스 통신의 정상 프레임과 오류 프레임 수를 확인할 수 있습니다|
|버스 사용률|현재 버스 사용률을 확인하여 버스 부하를 파악할 수 있습니다|
|그래프 분석|DBC/LDF 파일을 로드하면 CAN/CAN FD/LIN 버스 데이터 곡선을 표시할 수 있어 버스 데이터 변화를 한눈에 확인할 수 있습니다|
|E2E 보안 알고리즘|E2E 보안 알고리즘 라이브러리 가져오기를 지원합니다|
|UDS 진단|ISO 15765 및 ISO 14229 프로토콜을 기반으로 진단 매개변수 및 진단 서비스 구성, 다중 프레임 전송, UDS 기반 플래시 부트로더 구성, 자동 진단 등을 지원하며 ODX 파일을 지원합니다|
|ECU 플래싱|ZXDoc과 함께 사용하는 CAN FD 인터페이스 카드가 소프트웨어 및 데이터 정보를 ECU로 전송하여 ECU 관리 및 소프트웨어 업데이트를 지원합니다|
|SOME/IP|표준 진단 프로세스 및 ARXML 파일 가져오기를 지원합니다|
|XCP/CCP 교정|A2L 파일 가져오기, 교정 매개변수 관리 및 변수 곡선의 그래픽 표시를 지원합니다|
|그래픽 패널|스위치, 레코더, 표시등, 진행률 표시줄, 미터 등 다양한 COM 컨트롤을 제공합니다|
|시뮬레이션|CAN 버스 시뮬레이션/패널 시뮬레이션, 데이터베이스 로드 및 시뮬레이션할 노드 직접 선택|
|확장 스크립트|파이썬|
|서드파티 API|C++, 파이썬|
|운영 체제|Windows 7/8/10/11|
