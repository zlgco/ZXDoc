# ZXDoc
ZXDoc는 차량 연구개발, 시험, 생산 라인의 요구사항을 충족하기 위해 개발된 자동차 버스 툴체인 소프트웨어입니다. ZLG의 하드웨어 장치를 기반으로 CAN, CAN FD, LIN, 차량용 이더넷의 데이터 송수신과 데이터 재생, DBC/LDF 파싱, UDS 진단, ECU 플래싱, SOME/IP, XCP/CCP 보정, 시뮬레이션 등 다양한 응용 계층 기능을 지원합니다.

## 주요 특징
- 데이터 송수신
- DBC/LDF 송수신·파싱
- 그래프 분석
- UDS 진단
- ECU 플래싱
- SOME/IP
- 영상 동기화 재생
- 파이썬 확장 스크립트
- XCP/CCP 보정
- 시뮬레이션

## 기능 목록
|기능 유형|기능 설명|
|---------|---------|
|버스 프로토콜|CAN, CAN FD, LIN, 차량용 이더넷|
|장비 채널 수|제한 없음|
|하드웨어 필터링|호스트 PC에서 ID 범위를 설정하면 하드웨어 장치 컨트롤러가 해당 범위의 버스 패킷을 필터링합니다|
|소프트웨어 필터링|버스 패킷을 시간, 채널, 메시지 ID, 데이터 등의 요소로 필터링할 수 있습니다|
|메시지 데이터 전송|마이크로초(µs) 단위 주기의 원본 메시지 예약 전송, 트리거 전송, DBC/LDF 기반 전송을 지원하며, 신호 생성기도 설정할 수 있습니다|
|메시지 데이터 모니터링|원본 메시지를 실시간으로 표시하며, DBC/LDF/ARXML 로드 후 데이터를 파싱할 수 있습니다(DBC 신호 기반으로 작성된 ARXML 파일은 파싱 전에 ZXDoc에서 DBC 파일로 변환해야 합니다)|
|메시지 데이터 저장|ASC, BLF, MAT, MF4 등 다양한 형식의 메시지 저장을 지원합니다|
|메시지 데이터 재생|온라인과 오프라인 재생을 모두 지원하며, 재생 횟수, 재생 속도, 재생할 버스 데이터와 시간 범위를 설정할 수 있습니다|
|메시지 데이터 통계|버스 통신의 정상 프레임과 오류 프레임 수를 확인할 수 있습니다|
|버스 이용|현재 버스 통신의 사용률과 버스 부하를 확인할 수 있습니다|
|그래프 분석|DBC/LDF 파일을 로드하면 CAN/CAN FD/LIN 버스 데이터를 그래프로 표시할 수 있어 데이터 변화를 한눈에 파악할 수 있습니다|
|E2E 보안 알고리즘|E2E 보안 알고리즘 라이브러리 가져오기를 지원합니다|
|UDS 진단|ISO 15765와 ISO 14229 프로토콜을 기반으로 하며, 진단 매개변수 및 서비스 설정, 다중 프레임 전송, UDS 기반 플래시 부트로더 설정, 자동 진단, ODX 파일을 지원합니다|
|ECU 플래싱|ZXDoc과 연동되는 CAN FD 인터페이스 카드를 통해 ECU에 소프트웨어와 데이터를 전송하여 ECU 관리 및 소프트웨어 업데이트를 수행할 수 있습니다|
|SOME / IP|표준 통신 워크플로와 ARXML 파일 가져오기를 지원합니다|
|XCP/CCP 보정|A2L 파일 가져오기, 보정 매개변수 관리, 변수 곡선의 그래프 표시 등 다양한 기능을 지원합니다|
|그래픽 패널|스위치, 데이터 로거, 표시등, 진행 바, 계기판 등 다양한 COM 컨트롤을 제공합니다|
|시뮬레이션|CAN 버스 시뮬레이션/패널 시뮬레이션: 데이터베이스를 로드한 후 시뮬레이션할 노드를 직접 선택할 수 있습니다|
|스크립트 확장|파이썬|
|서드파티 API|C++, 파이썬|
|운영 체제|Windows 7/8/10/11|
